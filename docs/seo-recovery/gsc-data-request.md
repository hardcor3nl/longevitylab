# Google Search Console evidence request

Before changing or removing indexed YMYL URLs, export and preserve:

- Page-level clicks, impressions, CTR, and average position for the last 16 months.
- Indexing status and excluded-reason for sitemap URLs.
- Canonical-selected-by-Google versus user-declared canonical.
- Manual actions, security issues, and enhancements.
- Query and page exports for supplement, wearable, protocol, and comparison clusters.

Use the export to classify URLs as preserve, consolidate, rewrite, or noindex. Do not infer traffic value from the local sitemap alone.
