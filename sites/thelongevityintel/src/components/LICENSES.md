# Third-party code in the motion layer

No 21st.dev (or other pasted component) code is used. The motion pass (`src/scripts/motion.ts`, the "Motion pass" block at the end of `src/styles/global.css`) is first-party vanilla TypeScript/CSS with no runtime dependencies.

| Item | Source | Licence |
|---|---|---|
| Molecule field, card glow, count-ups, cost bars | written in-house for this site | proprietary (site owner) |
| Cross-document View Transitions | browser-native `@view-transition` | n/a |
